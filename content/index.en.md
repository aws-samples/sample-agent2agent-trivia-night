In this session, workshop participants will be asked to build a multi-agent team to help answer trivia questions about the life sciences industry, AI, and AWS

- **Type**: Workshop
- **Duration**: 1 hour
- **Level**: 300 – Advanced
- **Topic**: Artificial Intelligence, Industry Solutions

::alert[This workshop is only compatible with the AWS us-east-1 region]

## Target Audience

This workshop is intended for data scientists, ML engineers, and other builders who want to use teams of AI agents to solve life science challenges.

## Prerequisites

A basic familiarity with Python and Visual Studio Code is required.
